# 🎓 ETEC Itaquaquecetuba

Este repositório reúne os principais **projetos, exercícios e atividades práticas** desenvolvidos durante os três anos do curso **Técnico em Desenvolvimento de Sistemas integrado ao Ensino Médio**, na **ETEC de Itaquaquecetuba**.

Aqui estão registrados os conhecimentos adquiridos e aplicados ao longo da formação, envolvendo **programação, desenvolvimento de sistemas, banco de dados, desenvolvimento web e outras áreas da Tecnologia da Informação**.

### 💻 Sobre o repositório

O objetivo é documentar minha trajetória acadêmica e técnica, reunindo os projetos desenvolvidos durante o curso e demonstrando a evolução dos meus conhecimentos e habilidades em tecnologia.
